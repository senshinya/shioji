# 原生 UI 边缘与间距审查 · 2026-11-13

本轮按 AGENTS.md 与冻结的 `design/spec.html` 修整，保留已确认的灰阶、字号、页面结构和交互。审查方式：渲染源码逐页核对、原生亮暗/宽窄截图、几何与墨迹回归，以及重启真实测试客户端查看设备页。验收图在本机 Ryugi `artboard/verify-ui-spacing`，不发布到云端。

## 修正项

| 位置 | 问题与处理 |
| --- | --- |
| 设备路径、服务/身份折叠行、设备工作区行 | 反馈面贴着内容；共用行控件将反馈面与阅读边缘分离，两侧8 DIP，保留相邻文字基线 |
| 设置的消息输入/许可跳转行 | 同类贴边问题；补齐反馈内缩，分隔线单独绘制，保持原表单左右边缘 |
| 模型列表 | 收藏和开关贴着反馈边缘；改为行内两侧8 DIP，避免完整配置页的裁剪吞掉外扩留白。模型3.5行上限、排序和显示设置保留 |
| Skill列表 | 图标紧贴内部查看区；补齐8 DIP命中区留白，内容、状态和开关保留原列表节奏 |
| 工作区MCP列表 | 列表左右内缩与Skill不同；统一8 DIP内缩，状态与列表右端保持同一列 |
| 新建远程工作区 | 主目录按钮与附加目录加号/移除的右边缘相差6 DIP；统一按钮边缘 |
| 上下文压缩弹层 | 操作内容贴着命中区；补齐横向6 DIP留白，保留26 DIP紧凑高度 |
| 历史导入预览行 | 标题贴着内部按钮；补齐8 DIP留白，并列命中区保持分离 |
| 其他配置操作 | 恢复按键、添加变量、通知操作、许可返回和MCP管理补齐内部留白，保留原阅读边缘或与字段内部文字对齐 |

整行控件复用 `configuration_forms.go`，数值集中在 `configuration_layout.go`，没有新增表单描述或验证框架。图标继续复用原字体度量与公共基线，不添加逐文案位移修补。
