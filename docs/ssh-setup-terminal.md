# SSH 主机信任与设置终端

2026-11-09。添加设备和首次启动共用现有连接页：检查主机 → 明确确认未知主机指纹 → 检查现有 SSH 认证 → 必要时由用户启动密钥设置终端 → 重新核对 SSH 与 worker → Agent 配置。

已受信任设备先由系统 OpenSSH 直接核验，仅主机验证失败时进入指纹采集。主机扫描使用系统 OpenSSH 的实际配置，继承主机别名、端口及主机记录文件。扫描关闭所有账号认证与转发，只把新主机条目写进临时文件；已有记录冲突不作为首次信任。确认保存的是该次展示的原始条目，保存前再次检查所有配置的记录文件，不重新扫描并替换成另一把公钥。主机身份未知或变化时不传输凭据、不部署 worker。复制核对命令只操作剪贴板，由用户在目标 Mac 执行并比对指纹。

确认主机指纹后，若设备仍需 SSH 认证，直接展开系统 `ssh-copy-id` 终端；已受信任设备也保留“设置 SSH 密钥”入口。连接提交成功后，“连接选项”以真实高度动画收起，保留设备名称和端口；本地输入校验失败或提交未接纳时保持展开。安装失败或重检仍需认证时不自动重启安装，保留用户重试选择。`ssh-copy-id`，可能向用户询问目标账号密码或密钥口令。它在本机 MyGo 原生终端的真实 PTY 中运行；SSH 控制回显，Shioji 不提供独立密码表单，不解析或保存输入，不把终端输出写进会话、日志、草稿或数据库。OSC 剪贴板读写关闭，滚动回溯限制128 KiB，程序图片关闭。键盘、粘贴、Ctrl+C、窗口尺寸及终端字体由现有原生插件处理；首选代码字体不可用时显式回退到等宽字体。

终端使用独立的亮暗灰阶底色、内嵌命令标题栏、13 px 等宽字和1.15倍字体行高，保留闪烁块状光标与中性选区。标题、终端和底部操作沿现有实际高度动画同步展开收回；准备完成时标题文字过渡，原生终端内容渐显，均尊重减少动态效果。

设置终端是 GUI 的临时资源。取消／退出关闭其 PTY，关闭动画期间短暂保留已绘制内容；不停止 worker、已有会话或其他终端。后台创建不阻塞 UI。终端退出码0只触发真实 SSH／worker 重检，不能直接把设备标为可用；失败保留终端输出并提供重试。

普通连接仍使用密钥或 agent 的非交互认证。不会自动生成密钥、改动 SSH 服务配置、关闭主机验证或启用远程登录；无公钥、密钥未解锁或服务器要求持续的交互验证时，重检如实失败。本轮终端用于密钥设置，不新增全局终端导航或会话执行器。

终端复用已随 MyGo 提供的 Ghostty VT 插件，不引入 WebView。开发打包读取其固定版本清单，校验 SHA-256，复制 arm64 动态库和许可证到 app 资源目录，再对动态库和外层应用签名。生成的库不进入 Git；已打包应用不需要联网下载终端组件。

验证包含：隔离的真实 sshd（未知主机、确认后保存、变更密钥拒绝）、原始条目保存与并发信任冲突、真实 PTY 输入与关闭回显、取消清理、原生高度动画，以及字体缺失时的等宽回退。原生验收截图的 SSH 回执和终端程序明确使用隔离夹具；它们不代表已在用户的设备安装公钥。

连接初始化和普通重连在握手断开时，仅以只读握手识别已知 v1 服务，不向旧协议发送执行或更新命令；已保存设备仍核对原 DeviceID。旧版无安全更新入口时返回明确的版本及手动重启提示，保留旧 owner、数据库和 socket，不把它当成未启动服务，也不以 PID 信号自动接管。远端开发部署用结构化版本回执传回这个状态，避免将其显示为 EOF／exit status。
