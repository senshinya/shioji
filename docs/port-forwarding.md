# 全局快捷面板与端口转发

左下角的设备、Tailnet、端口转发入口共用 34 DIP 固定底栏，28 DIP 点击区域上下各约 3 DIP 留白。面板按内容收缩，最高 360 DIP，并受窗口可用高度限制。标题固定；Tailnet 本机节点和对端标题固定，超出的对端列表单独滚动。图标命中区为 28 DIP、槽位为 16 DIP；标题操作使用更小的 10 DIP 图形，统一按标题字面中心对齐。图标笔画范围与首行状态点通过原生像素回归检查。在线／离线状态同时供辅助功能读取。

手动转发固定设备、目标地址、目标端口和本机端口。本机端口占用时保留表单并提示错误；远程会话中的私网或回环 HTTP(S) 链接可右键选择“端口转发并打开”，优先申请同端口，占用或无权绑定时申请空闲端口。重复 URL 操作按设备身份和规范化目标复用。打开地址保留路径、query 和 fragment；完整 URL 只保留在内存。

普通 SSH 和内嵌 Tailnet 均经所属设备的认证 worker 字节流。每次新建流重新取得当前路径与私有 SSH 桥；不会调用系统 Tailscale CLI。新 worker 在 Welcome 中显式声明 TCP stream version 1，旧 worker 缺少声明时明确要求更新。此能力与普通 RPC minor 分开协商，避免并行功能的 minor 版本互相冒充。

本机只监听 127.0.0.1。创建成功要求监听、设备身份核对和远端 TCP 拨号全部成功；随后才打开浏览器。协议握手结束后只传输原始双向字节，保留半关闭；每条映射最多 32 个客户端流，建立超时为 10 秒。关闭同步阻止迟到的浏览器打开，并异步等待监听、流及 SSH 进程组释放。

转发属于应用进程，与会话和窗口独立。仍有转发时关闭主窗口只隐藏窗口，点击 Dock 恢复；真正退出 App 才释放转发。退出期间保留主事件循环，等待监听、所有设备连接、观察流和探测所属的进程清理完成。独立转发流可选健康备用路径，但不会提交主 RPC 的路径交接或改变其错误归属。状态使用可替换快照，后台转发不等待隐藏窗口消费 UI 更新。此功能不会持久化和自动恢复转发，也不改变 Tailnet 后台节点及入站转发的生命周期。

## 验证边界

- 真实 TCP 测试覆盖大响应、双向流、半关闭、32 流上限、占用端口回退、设备隔离、创建中取消、关闭释放和迟到打开。
- 真实 worker Unix socket 测试覆盖认证握手、目标拨号、二进制传输、错误设备身份及缺少能力声明的 worker。
- OpenSSH 进程管道测试覆盖半关闭、取消及所属代理子进程的回收；Tailnet 私有路由继续复用现有传输约束。
- MyGo 原生测试覆盖列表滚动、360 DIP 上限、高度收缩、开关与切换、表单原生输入、显式本机端口保留、中文／英文／混排状态点，以及亮暗主题 1×／2× 图标可见笔画对齐。
- 原生录屏使用生产 View 与 MyGo Native Tester；设备、Tailnet、延迟与已有映射是明确的数据夹具，不连接或修改用户设备。真实远程 SSH 设备和已授权 Tailnet 对端仍需端到端验收，不能把本地 worker 或路由单测描述成已完成远端验收。
- 功能分支早期基线的三个请求卡片布局失败已由最新 `main` 修复；合入后，相关回归检查均通过。本功能保留这些请求卡片改动。
- 合入设备负载功能时，补充验证退出会等待负载订阅连接清理；其回归先复现提前退出，再通过统一的网络任务等待修复。
- 当前仅做 TCP 字节转发；不会改写 HTTPS 证书、Host、Origin、重定向或页面内的绝对 URL。依赖特定域名的服务仍需自身配置。本轮不实现 UDP、反向转发、SOCKS 或自动恢复。
- 延后的小问题：浏览器打开失败会显示全局错误并保留可重试的映射，尚未把该错误保存在映射行内。

完整交互约束见 [批准的设计](ryugi/specs/2026-11-15-port-forwarding-design.md)。
