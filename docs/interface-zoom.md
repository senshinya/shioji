# 会话界面整体缩放

已实现的用户需求：在会话中按住 Cmd 并滚动，缩放界面的整体元素。

本轮工程默认：向上放大、向下缩小，范围 75%–150%；Cmd+0 恢复 100%。比例作为本机 `preferences.interfaceZoom` 保存，启动时恢复。旧状态缺失或无效时使用 100%。

主窗口通过 MyGo `Context.SetZoom` 重新排版和原生绘制，文字、图标、间距、侧栏、工具栏和输入框采用相同比例。它独立于回复字号偏好。设置窗口有自己的显示上下文。

MyGo 的 `Context.OnScroll` 在子控件、编辑器、弹窗和滚动容器前接收滚轮事件，仅消费 Cmd 的纵向滚动。普通滚动沿用既有分发；Cmd 手势不滚动正文或触发历史分页。触控板增量换回窗口距离，避免当前倍率改变缩放速度；惯性不继续改变倍率。注册随每次构建更新，窗口关闭后释放。

窄窗口允许运行配置按钮和模型文字收缩，完整名称保留在 tooltip 中，权限和发送操作保持可见。

缩放时复用 MyGo 原生 toast 显示当前整数百分比，例如“缩放 111%”。连续调整更新同一个提示，最后一次调整约 1.5 秒后消失；Cmd+0 显示“缩放 100%”。启动恢复和普通滚动不触发提示，提示不进入操作消息历史，也不改变输入焦点。
