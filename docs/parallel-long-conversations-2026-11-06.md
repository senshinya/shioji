# 双会话与长对话

状态：原生接通、自动验证通过；已取得亮暗／窄窗截图，人工待验收。沿用冻结稿 `design/index.html` 的双栏和 `design/outline.css` 的阅读导航几何。

- 会话工具栏选择并排会话，侧栏上下文菜单也可在右侧打开。两个会话分别保留普通草稿、附件、运行配置、队列编辑、问题页、工具折叠及滚动位置；发送、Stop、审批和回答只针对当前输入所在会话，不广播。关闭右侧只改变视图，不停止任务或删除草稿。
- 点击会话内容决定焦点所属，侧栏导航在该侧打开；不增加顶部任务标签。右侧栏全窗口只有一个，随焦点会话显示 Diff／任务，并保留原有合并／上下分区与拖拽宽度。窄窗保留两个会话的状态，只显示当前一侧，允许切换。
- worker 的执行与可见会话无关。控制器记住两个可见会话，重连后分别按事件屏障补读；重新打开已从缓存淘汰的会话必须再次补读，不能把旧 loaded 标志当作数据仍在。
- 多条已发送用户消息时出现阅读 tick rail：10 px 节距、2 px 线高，6 px 静止宽度；悬停位置前后各三项展开到 26 px。延迟 300 ms 显示提示／回复预览；悬停不改变阅读位置或输入焦点，点击跳转，窄阅读边距隐藏。队列草稿不产生刻度。离开自动底部跟随时提供回到最新。
- 轨道由一个有界原生 List 负责滚动，不嵌套额外 Scroll；轨道不显示滚动条或让其拦截指针。头尾既有 8 px 留白归入首末按钮命中区，刻度笔画位置、10 px 节距与预览锚点保持原样。末条下缘可悬停、预览并点击返回，长列表滚至末尾后仍可完整命中最后一条。
- 延续原有每条消息内的原生文字选择，使用稳定消息 key、段落 identity 与 rune offset 保留逻辑选区。虚拟行卸载后只保留选中段落与复制数据；Copy 仍可用，重新挂载恢复选区。删除或替换来源会使其失效，追加内容保留已有偏移；不会让回收后的状态继承选区，也不抢普通输入框或另一个编辑器的复制。没有通过挂载整段历史或保留焦点行来规避虚拟化；跨消息拖拽选择并非本轮新增能力。
- 两个可见会话保留完整已补读投影；另外最多缓存六个近期历史，总文本预算 16 MiB。淘汰仅影响可重新补读的历史及其 UI 缓存，草稿、请求答案和执行状态保留。附件缩略图最多 32 个，图片解码最多两个并行，预览与原始资源分开。

测试包含双侧发送隔离、单一侧栏、关闭保留草稿、布局持久化、两个可见会话重连补读、历史缓存上界、导航不抢焦点，以及真实虚拟行卸载后的复制／重新挂载／来源替换／其他编辑器焦点。
