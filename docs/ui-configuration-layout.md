# 原生配置页面的排版尺度

工作区设置保留全宽、原有字号、间距及操作位置；只校准标题与设备名的字面中心、目录路径与主目录标记的基线，以及目录操作图标的共同中心。目录选择标记向右内缩 4 DIP，路径列保持原位。不得再引入居中限宽列或重新排列名称、目录和页尾操作。

设置、设备管理、欢迎页与添加设备流程共用 `internal/ui/configuration_layout.go` 的数值。保留现有灰阶、原生字体和页面层级，不新增说明文案。

| 元素 | 数值（DIP） |
| --- | --- |
| 页面标题 | 20 / 28，字重 400 |
| 分组标题 | 14 / 28，字重 500；其后 8 留白 |
| 单行设置／表单／列表行 | 40 高 |
| 字段名称 | 13 / 20，字重 400 |
| 控件与状态文字 | 12 / 20 |
| 常规控件 | 28 高 |
| 分组与页尾操作间距 | 24 |
| 页标题与内容间距 | 20 |
| 设备／设置内容左右内缩 | 32 |
| 模型与 MCP 内部列表上限 | 140，约 3.5 条 |

初始化内的模型标题保留紧凑的 28 高，Tab 到内容保留 12 间距。设备列表和 Agent 列表含身份与状态两行，保留相应的两行高度。欢迎页的步骤指示、模态页上下文标题与“关于”的产品名称有各自的层级，不冒充配置行。

图标按 AGENTS.md 的实际字面与原生字体度量校准。字段列、分隔线、选择器和开关各自对齐固定边界；窄窗口不改变同一内容列的左边界。横向 Tab 内容按顺序左右滑动，选中指示连续移动，使用260 ms EaseOut，不做淡入淡出；设置侧栏的纵向分类保持即时切换；既有展开、收起和状态更新使用原来的真实高度与内容动画，并遵循减少动态效果。

共用实现：`configuration_forms.go` 负责三种现有布局中的表单行、单行／多行输入、选择器、标题与操作按钮；`settings_switch.go` 保留历史文件名，提供共用灰阶开关；`configuration_tabs.go` 负责下划线 Tab、分段选择、不透明的左右内容切换，以及保持即时切换的侧栏分类。职责限于原生排版与交互，不接管配置验证、存储、授权或后台生命周期。

横向切换以完整内容块为运动单位：初始化配置包含表单与错误；账号/API 模式包含完整常规表单。导航、模式选择器与共用取消／保存操作不参与横向切换。共用操作在裁剪区域外跟随表单真实高度，不叠加位置缓动；同一页内展开内容不再被外层高度动画重复处理。不要对子项逐个播放入场动画。

设置的“关于 → 第三方许可 → 单项许可”沿相同的 260 ms EaseOut 规则切换完整内容页。进入时新页从右侧滑入，返回时新页从左侧承接、原页向右滑出，文字与背景始终不透明；返回动作不提前替换正在退出的许可正文。快速返回承接当前位移，减少动态效果时即时切换；设置侧栏分类和首次进入“关于”仍不播放切换动画。
