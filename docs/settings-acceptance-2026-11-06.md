# 设置界面审查与待验收项

采用用户选定的 A 方向，在独立原生窗口中提供外观、消息输入、通知、快捷键和关于。后续明确反馈覆盖早期设计稿：无右侧总标题、无当前 Mac、分类切换无动画、分组无外框、灰阶胶囊开关。

## UI 审查

| 问题 | 修正与证据 |
| --- | --- |
| 红绿灯数值相同但视觉边距仍不同 | 两窗共用定位函数，设置侧栏恢复主界面的 8 px 内缩卡片。AppKit 实测两窗均左 22、上 21 DIP |
| 搜索离窗控太远，文字起点与导航不齐 | 搜索外框顶部 48 DIP，文本起点与导航文字共列，边框宽度计入内距 |
| 通知总开关仍为按钮 | 所有通知项使用相同灰阶 switch，34×20 DIP 轨道，40×28 DIP 命中区 |
| 通知页分隔线重复，组框过重 | 行高至少 44 DIP，仅保留每行底部 0.5 DIP 分隔线 |
| 主题缩略图过扁，选中文字被覆盖 | 缩略图 134 DIP 高，选中保持正常文字颜色；边框宽度恒为 1 DIP，避免选择时位移 |
| 快捷键控件右端内缩与其他控件不齐 | 消息输入键位取消额外右内距，与快捷键页及分隔线右端共线 |
| 关于页版本被拉成全宽灰条 | 改为普通次级文字；信息本身不再制造多余表面 |
| 查看文字与箭头直接相贴 | 统一 8 DIP 间距，按同一原生字体度量对齐文字与箭头 |
| 输入页无功能的示意框 | 移除；仅外观页保留真正响应字体字号的 Markdown 预览 |

审查覆盖 968×756、760×600 窗口及亮暗模式。截图来自运行中的 MyGo 原生窗口，位于本地设置画板的 Verify 页。原生内容捕获不包含 AppKit 窗控，窗控位置通过持有的 NSWindow 与按钮实际 frame 单独读取；不将内容截图冒充含窗控的桌面截图。系统桌面截图服务当前连接失败。

## 行为与验证

- 客户端偏好持久化，不改变设备、工作区、会话草稿或正在执行的模型请求。
- 通知仅由已确认的运行时事件触发，正文仅含会话名称，原生通知点击回到对应会话。通知对象最多保留 64 个，事件去重记录最多 256 条。
- 通知授权结果通过原生窗口更新提交，不依赖设置页下一帧；异步保存错误在设置窗口展示。MyGo 通知注册在锁内复核上下文取消，避免取消与注册的竞态。
- 前台通知默认开启；旧偏好缺失该字段时补默认值，明确关闭仍保留。
- 已在隔离验收应用中获得 macOS 通知授权并成功提交测试通知；不推断横幅实际可见，也不代表生产应用身份已获授权。
- 全量 Go 测试、app/ui race 测试、go vet、MyGo 相关测试、第三方许可清单核验及冻结设计校验通过。用户于本轮回复“lgtm，commit and push”，确认界面并授权提交推送。

## 审查方向

产品：管理多设备编程会话的原生 macOS 客户端。性格：克制、精确、安静。材质：中性 macOS 工具表面。内容重点：真实对话排版预览。特征：主界面与设置共用窗控、排版度量与紧凑导航。
