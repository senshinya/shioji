## 新增部分的动画补齐

- 双会话单／双栏使用同一左栏节点与 ListState，宽度和右侧进入／退出同步为 200ms；快速反转从当前位置继续。窄窗切换在原位置淡入淡出。
- 附件卡片删除后的补位为 180ms；整条附件区以 360ms 实际高度顶起／收回输入框。移除原先外层独立的附件高度驱动，避免两层动画追赶。缩略图完成解码后在固定槽位淡入。
- 工作区目录行增删与后续行、底部操作同步为 180ms；主目录标识淡入淡出。名称冲突、多行标题和预览加载完成后，弹窗按测量内容连续调整实际高度，避免浮层二次布局覆盖尺寸过渡；弹窗和遮罩一起进出。
- 新增 8 个原生时钟回归检查，先观察原代码的跳变失败，再修正；包括开合、补位、加载高度、遮罩、快速反转、输入焦点、草稿及 Reduce Motion。根仓库完整测试、vet、冻结稿校验通过，开发包重新构建签名；原 worker 保持运行。

原生前后采集使用相同隔离 worker 和各自独立的客户端状态副本，覆盖亮暗模式。约 70/100ms 为截图采集请求时间，不冒充精确视频帧；动画连续性另由原生 Tester 时钟和几何检查验证。所有视觉 verdict 仍待人工确认。
