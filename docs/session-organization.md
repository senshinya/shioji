# 会话置顶与侧栏排序

置顶是当前客户端的导航偏好：跨工作区、跨设备的置顶会话集中在“待我处理”下方，普通分组不重复展示。菜单取消置顶恢复原普通位置；拖回所属工作区则使用指定位置。普通会话不能拖入其他工作区，工作区标题可整组排序。新回复不重排，新会话前插到普通区。

偏好由 `internal/app/navigation.go` 以 DeviceID / WorkspaceID / SessionID 保存，独立于 worker 快照与 harness；离线或尚未加载的目录不会删除已有偏好。归档内容沿用原有可见性。当前实现不把一个客户端的排列同步给其他客户端。

原生侧栏在 `internal/ui/navigation.go` 和 `navigation_drag.go`。同一虚拟列表保留稳定会话 key，顺序变化以 180 ms EaseOut 承接当前位置；已有的高度显隐负责新增/归档，避免叠加缓动。放置依据原生列表实际显示的行，不使用未测量行的估算高度。减少动态效果时立即换位。

拖动只更新临时预览，释放才写导航偏好；Esc、越界、其他工作区或归属失效均不提交。拖动期间导航目录新增或排列被其他操作修改时取消本次拖动，保留新目录；状态和标题变化不取消。菜单上下移动及聚焦后的 Option+上下提供键盘替代。排列保存走已有异步状态写入器，失败恢复最近确认的排列，保留当前会话和草稿。

验证覆盖全局混排、取消恢复、保存/重开、离线偏好、实际菜单/键盘输入、拖动实时让位/释放/取消、跨工作区拒绝、500 条会话滚动后插入、减少动态效果与存储失败回滚。全量 Go 测试、冻结稿校验、相关包竞态检查和开发构建另行运行。

本轮原生截图与交互回放使用生产 View、原生输入和真实状态持久化；设备目录与对话内容为隔离的静态夹具，不启动 worker、模型或 SSH。它们证明客户端导航交互，不代表新增远程执行验收。
