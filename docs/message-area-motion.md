# 消息区动态内容

本轮按“已有消息内部追加”的路径核对原生消息区，沿用现有灰阶、字形对齐与减少动态效果设置。

默认折叠的工具摘要或自动压缩状态接替“进行中”时共用原有 24 DIP 状态占位；新状态的 20 DIP 行高只补齐该占位，不再叠加段落间距。原状态行按新状态实际入场进度交还高度，避免两条时间线使底部跟随产生额外滚动。`internal/ui/tool_start_scroll_test.go` 逐帧核对亮暗主题、减少动态效果、首个折叠工具与自动压缩入场，以及已有工具阶段变更；两条替换路径修改前均稳定复现 4 DIP 位移。

2026-11-16 的原生旁路检查还复现两项未修问题：请求来源行与底部问题面板同时出现时，来源行占位仍多出 4 DIP，动画期间相对面板的阅读间距最大偏差约 25 DIP；待发队列展开和收起时，底部保留高度由绘制后测量更新，消息区比面板晚一帧跟随，夹具中最大偏差约 19 DIP。以上数值来自确定性原生夹具，并非所有内容长度的上限。向上阅读历史时，两类操作均未改变被测消息锚点。旁路复现代码与结果保留在本地 `.ryugi/audits/reading-position/`，通过 Go overlay 运行，不将已知失败的审计探针混入常规回归套件。

| 区域 | 处理 |
| --- | --- |
| 正文、代码块 | 保留真实增量的 Markdown reveal，不重播已显示前缀。 |
| 工具标题、摘要及其他事件 | 实时新增行渐显并展开实际列表高度；会话切换、重连水合和历史回看建立基线。 |
| 工具内文件、图片、文本、代码、补丁、子任务 | 每块独立进退，外层测量实际高度；同一资源多次出现用 occurrence 区分，删除首项不复用另一资源的动画状态。 |
| 工具内追加文本 | 仅新到的字节渐显，已有内容保留；保留实际 RichText 的选区和搜索几何。 |
| 图片加载、失败、重试 | 新像素、状态文本和重试入口均有过渡；图片自身高度变化直接交给外层布局，不再叠加一层缓动。 |
| 工具状态、结果标签、移动目标、截断提示 | 补齐条件元素的进退和状态文字变化。 |
| 用户消息操作 | 编辑入口及复制/勾形切换有过渡；保持原有原位编辑、碎散和发送动画。 |
| 回复底栏 | 进行中/断开/停止/失败/完成在稳定底栏内交接；迟到的时间、用时和用量有文字过渡。历史重开中的本地进行中交给真实 turn 时保留同一个虚拟行身份及原生控件状态，入场、绿点呼吸和文字扫光不重新起播；正文先到或输入先绑定均连续交接。 |
| 问题、授权、回答回执 | 保留现有实际 dock 高度、横向分页、请求移入/移出、回执先于后续正文的时序；不加整张请求卡淡入淡出。 |
| 恢复及错误提示 | 恢复模式切换、详情、状态文字和错误提示均有过渡；错误提示收起保留布局高度至动画完成。 |
| 消息导航 | 保留回到最新、会话搜索、大纲预览的既有过渡及阅读锚点。 |

`internal/ui/message_motion_test.go` 检查新内容的中间帧、后文高度同步、既有文字不重新渐显、重复资源、搜索高亮、重连基线和 Reduce Motion。动态效果只影响展示，不改变 worker 的执行和请求状态。

工具展开时，仅上方“执行工具”标题行可以收起，箭头紧跟文字右侧；明细末尾的次数摘要只展示当前阶段与计时，无箭头、点击或悬停反馈。折叠时不保留额外标题，只展示单行次数、状态与计时；该行接替标题作为展开入口，并在摘要末尾保留向右的展开箭头，完成后同样保留；展开后的底部摘要不显示该箭头。轮次结束后，无论展开或折叠，都直接以“x 次工具调用”作为唯一标题，次数、未成功计数和箭头依次相邻；不再显示“执行工具”及底部重复次数。标题保持同一阅读锚点，调用明细和结束回执位于其下。正文到来后，旧摘要沿现有交接时间线让出运行状态；请求由底部 dock 承接。向上阅读时，只要“回到最新”按钮出现且当前仍在工作，按钮就展示最新状态指示器、阶段文案与计时，不再等待正文状态行完全离屏；阶段直接跟随当前轮次更新，不依赖绘制后的可见性测量。请求等待期间及结束后恢复“最新消息”，断线时显示静态“状态待确认”且不继续计时。返回后按钮随跟随末尾状态消失，不抢输入焦点。展开与收起都保持标题位置，折叠后的单行摘要承接同一锚点；使用虚拟列表的可见裁切范围，不为维持锚点制造额外空白。`internal/ui/tool_tail_test.go` 与 `internal/ui/latest_test.go` 覆盖亮暗主题、标题锚点、减少动态效果、近底部阅读、离屏返回及断线／结束等状态。

普通草稿换行、粘贴多行和缩短时，编辑器的基础高度使用 180 ms EaseOut 真实布局过渡；“回到最新”指示器直接跟随同帧 dock，不另加位置缓动，始终保留 12 DIP 间距。队列编辑沿用原有 360 ms 时间线，附件栏已有的高度动画仍直接相加。首次展示不从零高度展开，减少动态效果直接切换。`internal/ui/latest_position_test.go` 覆盖亮暗主题、展开／收起、快速反向、阅读锚点、草稿与输入焦点；可选原生录制使用 `SHIOJI_LATEST_POSITION_RECORDING` 指定绝对输出目录。验收媒体为生产 View 的 MyGo 原生测试渲染及确定性草稿夹具，不代表真实 worker 执行或 App 实测帧率。

会话正文的流式增量只揭示新文本，同时以 180 ms 过渡其真实高度，下面的运行状态随布局连续移动，不再按新增段落的 32 DIP 高度跳动。新正文入场、历史／虚拟行重新挂载分别建立正确基线，工具转正文沿用已有状态交接，不叠加首段入场时钟。新增工具继续复用明细已有的高度动画；工具摘要的阶段文案补齐内容过渡，常规状态的短文案扩大时平滑让出计时位置，缩短时仍保留退场文字至渐隐完成。最新消息胶囊的空计时槽不参与基线对齐，避免未知计时和断线时文字被下推约 6 DIP。`internal/ui/running_caption_motion_test.go` 与 `internal/ui/latest_alignment_test.go` 检查正文／工具新增、文案切换、胶囊字面居中及有无计时；`SHIOJI_PROGRESS_RECORDING` 导出亮暗主题的原生会话录制。

会话内的子 Agent 工具调用、思考、文件、搜索与 MCP 活动使用相邻的“名称 → 状态 → 折叠箭头”，不将状态推到阅读列最右端；等待的时长与状态也紧随名称，但不提供折叠箭头。子 Agent 状态事件直接展示图标与“名称 已开始／有新活动／已完成／已中断”，不折叠，不显示事件记录本身的完成状态；点击不改变展示，保留原生文字选择。主会话及子 Agent 内的命令只在有可展开输出时显示箭头。长工具标题在原阅读列内缩短，为状态和箭头保留空间，完整名称可悬停查看。右侧子 Agent／后台任务列表的进入详情箭头、底部请求卡的分页和操作保持各自语义。回归与原生录制见 `internal/ui/tool_summary_order_test.go` 与 `internal/ui/agent_activity_test.go`。

会话内容横向裁切到与发送框相同的阅读列，避免长内容或深层缩进越过右基线；纵向保留发送消息的原生 Lift 路径。顶栏覆盖整栏，控件和遮挡层为原生滚动条保留独立区域。底部卡片上圆角外侧保留历史内容；发送框两个下圆角外侧以页面底色遮挡，并延续到下方留白，阅读历史、展开队列和改变草稿高度时不透出后文。完整滚动区和原有阅读锚点保持不变。`internal/ui/conversation_occlusion_test.go` 检查顶栏宽度、上下圆角的不同遮挡边界、底部像素遮挡与右缘约束。

带附件的消息入队与队列编辑保存时，附件栏的实际高度（含相邻间距）只缓动一次；外层编辑框只缓动其余内容的基础高度，再直接加上附件栏本帧高度。基础高度保留原生测量精度容差，避免浮点误差反复重启缓动。已接纳的附件从草稿立即移除，展示快照保留到退场完成并停用交互。`internal/ui/queue_images_motion_test.go` 覆盖首次／已有队列、保存带图编辑，以及回执先于队列事件的逐帧高度和图片连续性。

子 Agent 请求继续使用同一 dock 的实际高度和 240 ms 左右分页动画；来源链接以宽度过渡收起，详情导航沿用同栏水平切换。子详情使用独立、有界的实时内容时钟：历史和重新打开建立静态基线，回答回执完成 200 ms 入场后才开始其后正文的 Markdown reveal，不延迟接收或伪造执行数据。失败信息留在请求内部，出现和实际高度同步，不改变页码、草稿和正常输入框焦点。回归见 `internal/ui/child_requests_motion_test.go`。
