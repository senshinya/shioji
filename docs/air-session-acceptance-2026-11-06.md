## 修复

1. 新请求没有检查读者是否离开最新位置或正在编写普通消息，因而自动展开。新增原生失败回归后，首次实时到达现在在阅读旧消息、输入非空草稿时保持紧凑；跟随最新且输入为空时仍可打开，已有折叠选择保留，用户可主动展开。请求进入和实际高度动画继续使用现有实现。
2. Darwin 的 `SysctlKinfoProc` 将已退出 PID 的空结果映射为 `EIO`，旧实现将其当作无法核对所有权，阻止 runtime 重启。本机与 Air 均复现。现在仅在 `EIO` 且额外的 signal-0 只读探测确认 `ESRCH` 时清理旧记录；仍存在的进程继续阻挡新 runtime，不终止或替换它。新增真实子进程退出回归在旧代码失败、修正后通过；原存活进程保护回归保留通过。

验证：根仓库完整 `CGO_ENABLED=0 go test ./... -count=1`、`go vet ./...`、冻结设计仓库校验、开发包签名构建通过；所有权保护、死进程恢复和待答问题重连的 worker race 检查通过。没有修改冻结稿、依赖或传输协议版本。

后续按用户反馈，将“继续队列”从通用按钮默认字号改为系统字体、12px、常规字重、18px 行高，保留 26px 操作高度和右侧对齐。1440px／850px 的原生亮暗前后及 hover 截图已核对，队列相关回归通过，开发包重新构建。证据位于忽略的 `build/queue-continue-style/` 与 `artboard/verify-queued-turns` 的“继续队列 · 字体”页；用户已确认并授权提交。

## 证据与未覆盖项

本地截图、运行入口及汇总报告位于忽略的 `build/air-session-acceptance/`；`latest-run.txt` 指向本轮私有客户端目录。该目录保留真实并发、附件、第二客户端下载、长历史、崩溃和清理报告。局域网验收页为 `artboard/verify-air-sessions`，13 张原生截图；无新录屏、无云发布。

本轮断线通过结束验收客户端自有 SSH 通道复现，未切换真实 Wi-Fi、让设备休眠或重启系统；不将这些电源／网络场景标为通过。worker／harness 崩溃后的未知状态保护不等于在途任务已自动恢复。正式签名／公证／安装升级、旧版 macOS、VoiceOver 和物理 IME 不在本轮验收内。
