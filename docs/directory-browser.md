# 工作区目录选择

欢迎页的主目录和附加目录均可选择文件夹。本机使用 macOS 原生目录选择器，支持一次添加多个附加目录；通过加号选择附加目录；取消不新增空行，不修改已有草稿。远程使用共用的 MyGo 原生目录弹窗，接入欢迎页、新建远程工作区和已有工作区的附加目录入口。手动输入仍可使用。

远程列表由该设备的 worker 通过 `device.directories` 提供，协议 minor 23 起可用。旧服务会明确提示更新，不把远程路径交给控制 Mac 的系统文件选择器。目录浏览不依赖 Agent，也不扩大会话已接纳的执行目录；创建或修改工作区时仍由所属 worker 重新验证目录。

弹窗支持单击选择、双击／Enter 进入、返回、上一级、用户目录、直接输入路径和显示隐藏文件夹。默认从已有路径的父目录开始；未指定路径时使用 worker 用户目录。仅列出文件夹及指向文件夹的符号链接，忽略普通文件；按名称排序，每次返回 200 条，长列表可继续载入。空文件夹可选，读取失败保留返回和重试。

请求绑定设备 ID、连接 epoch、调用方草稿及递增的读取序号。关闭、切换连接或更换草稿后，迟到结果不能重新打开弹窗、覆盖新列表或回填错误设备。选择结果按稳定的附加目录行 ID 回填，不依赖可变的切片指针。

首次打开及首次读取完成都原地展示目录内容；之后进入／返回目录复用现有 260 ms 不透明左右切换；标题、路径栏和操作栏留在裁剪区外。弹窗在最终位置渐显，关闭时保持原内容并原地渐隐，不缩放或移动；加载、空目录、失败保持相同尺寸。减少动态效果时跳过位移。图标使用既有 28 px 按钮、16 px 槽位与原生字体基线度量。

设计及原生截图保留在本地 Artboard `remote-folder-picker`。目录布局截图使用明确标注的样例数据；真实 MBA 验证单独使用临时 worker 和仅存在于 MBA 的目录，经 SSH 和正式协议读取后清理，没有替换原有服务或修改认证凭据。
