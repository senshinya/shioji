# 跨设备创建工作区

状态：用户于 2026-11-16 确认 Ryugi 交互稿并要求实现。原生实现与自动验证完成，两个原生验收组等待用户确认。

设计输入：`.ryugi/artifacts/artboard/workspace-create-device/`（浅色、深色、窄窗口可点击稿）。产品实现继续使用 Go / MyGo 原生组件。

## 入口与流程

- 侧栏工作区 + 是全局入口，当前会话断连不禁用。菜单列出本机与显式添加的设备，同一稳定设备不按连接路径重复展示；使用设备显示名称和图标。
- 菜单标题「新建工作区到」，26 DIP 行高、13 DIP 标签、14 DIP 行内图标、28 DIP 图标按钮，中性悬停与键盘焦点。当前设备作为初始键盘焦点；支持方向键、Enter、Esc 和点外侧关闭。
- 选择已连接设备后进入其已有创建流程。本机使用系统目录选择器；远程创建表单明确显示所属设备，主目录与附加目录复用 owning worker 目录浏览器。
- 选择未连接设备后在菜单内显示正在连接；失败原位提供原因与重试。连接成功继续创建。关闭菜单或另选设备后不再自动弹出旧目标表单。
- 「添加设备…」复用完整已有 SSH 添加与授权流程，保存连接后等待该设备 worker 就绪，再继续创建；取消或保存失败不得误继续。保留现有的 Tailnet 添加入口与鉴权行为，不以加入 tailnet 代替设备授权。
- 设备详情中的 + 继续直接绑定该设备。

## 状态与安全边界

- 选择设备、连接、取消创建均不切换原会话，不修改会话和首页的普通草稿。创建回执确认后才选中新工作区，进入首页，不创建空会话。
- 创建表单草稿按设备隔离；取消后在本次窗口生命周期内保留。设备身份改变时不复用旧目录。
- 每次打开创建流程有独立请求身份；迟到目录或创建结果不能改变新流程、其他设备或已取消操作。创建提交与回执核对目标 DeviceID、连接 epoch 与对应工作区。
- 关闭创建表单不代表撤销已接纳的 worker 操作；迟到成功可以更新该设备目录，但不得抢夺导航。
- 不修改冻结设计、真实凭据、Tailnet 身份、已有连接与执行权限。
