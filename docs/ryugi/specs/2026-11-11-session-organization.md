# 全局会话置顶与侧栏排序

依据：用户已确认 `artboard/session-organization` 最新全局置顶稿（proposal light/dark；details menu/drag/blocked/rules）。本轮实现原生界面，不把 HTML 原型带入产品。

## 行为

- 待我处理下方、工作区列表上方显示独立置顶区。置顶会话跨工作区、跨已添加设备混排；从普通列表移出，同一会话只显示一次。空区隐藏；拖动时可在顶部首次置顶。
- 左侧状态保持原语义；右侧灰图钉与悬浮菜单使用共同槽位。悬停可见工作区与设备，不增加第二行。折叠工作区不影响全局置顶入口。
- 菜单支持置顶、取消置顶及上下移动；聚焦会话时 Option+上下移动。取消置顶回到之前的普通位置；拖回原工作区可指定落点。拖入其他工作区无效，不能迁移执行上下文。
- 会话在普通列表内排序，工作区按整组排序。相邻行实时让位，松手直接保存；Esc、窗口外释放、归属失效取消。新消息不重排；新会话放在普通区手动排列之前。
- 排列是当前客户端的持久导航偏好，用稳定 DeviceID/WorkspaceID/SessionID 定位，不依赖连接别名、在线状态或 harness。保留未加载及离线设备的偏好，不把迟到快照当作删除。归档内容沿用现有可见性。
- 整理不切换当前会话、不改草稿、正文滚动或工作区归属。存储失败恢复最近成功保存的排列并显示简短反馈。

## 界面与动画

沿用侧栏 8 DIP 内缩、28 DIP 命中区域、13 DIP 会话文字和原生字面基线。列表保留虚拟化及稳定 key。位移、让位和落位使用 180 ms EaseOut，承接当前动画；菜单沿用既有原生菜单。置顶区首条出现和末条消失具有实际高度动画，空区拖动提示不挤动列表；减少动态效果立即完成。

## 验证

模型：跨设备唯一展示、固定顺序不受消息影响、新会话前插、取消位置恢复、保存重开、断开和迟到目录不丢偏好、错误归属拒绝。
原生 UI：菜单和键盘、工作区折叠、拖动预览/落下/Esc/越界、跨区归属、空置顶、实时让位/落位/减少动态效果、保存失败回滚。
全量 Go 测试、冻结稿校验、相关包竞态检查及开发构建。实际 MyGo 窗口截图/短交互回放放到原设计 Artboard 的 Verify 页，等待用户验收；不在本轮自动推送。
