# 手动上下文压缩与 /compact

用户已同意补齐长会话的手动压缩，并要求支持 `/compact`。已实现共用操作、菜单与生命周期；交互稿中的模拟流程与原生实现截图分开展示。

## 交互

- 现有上下文圆环继续用 hover 打开详情，在下方增加一个 26 DIP 的“压缩上下文”操作行，右侧标 `/compact`。复用已有灰阶、13/12 px 字号、14 px 图标与文字度量；圆环、模型和发送按钮位置保持。
- `/` 菜单增加本地内置 `/compact`，与异步 Skill 结果共处同一弹窗，分隔后展示 Skill。过滤保留同一弹窗；内置命令可立即出现，Skill 结果迟到不能覆盖选择、反复开合或抢焦点。
- 当前主会话 composer 中，独立的 `/compact` 经回车或发送按钮执行；菜单选中命令后回车直接执行。IME 组合、Shift+Enter 换行及 Esc 保持既有原生行为。命令不作为普通消息发给模型，也不加入待发送队列，不触发标题生成。
- 首版命令只接受无参数形式。携带额外正文、附件、Skill／文件引用时保留输入并给出行内错误；输入中间、代码、历史编辑框和子 Agent 输入里的相同文字保留普通文本语义。首页没有现有线程，菜单可显示禁用命令并说明“开始会话后可用”，不创建空会话。
- 浮层入口保留普通草稿与附件；命令入口仅在 worker 确认接纳后清除原命令草稿，期间新输入与另一会话草稿保持独立。明确未发送时保留命令；结果未知时只核对，不重放。
- 闲置、在线且实际运行时声明支持时可用。当前回复、子 Agent／后台执行、待处理请求、未知执行、上下文改变或已归档时禁用并给出具体 hover 原因。暂停队列保留暂停；正常队列在压缩执行期间等待，不越过当前操作。
- 压缩状态沿用现有中立 compaction 内容和圆环旋转。接纳前后的临时状态与真实事件承接同一节点、同一位置，旋转相位保持；消息进入／退出用现有真实高度与渐显动画，使用量数值翻动、圆环连续插值。没有新报告时继续展示上次用量，不凭完成事件推算减少量。尊重减少动态效果。
- 真正完成、失败和中断分别展示对应状态；失败在原位置给重试。压缩不发送普通回复完成通知，不改会话名称、正文历史或普通回复 footer，不移动用户的阅读位置。

## 实现边界

- 共享中间层增加明确的压缩 capability 与中立命令；具体方法、线程和通知结构只在 adapter 内翻译。不建立通用命令插件框架。
- 所属 worker 在现有 dispatch 序列化边界核对会话、revision、执行目录、Git 上下文、未决输入、请求及独立执行；能力取实际会话运行时，不以新安装目录替代旧进程能力。旧会话需要恢复观察时沿用现有安全恢复路径。
- 接纳必须先持久化稳定操作 ID 和执行占用，再调用 adapter。共用回执、重连与恢复边界，重复 ID 只查结果；显式拒绝与已发送但未知分开。压缩专用轮次无用户输入，不以 `input:<ID>` 作为已送达的证明，也不伪造用户消息来复用普通发送。
- Codex 0.167.0 的生成 schema 中 `thread/compact/start` 只接受 `threadId`，无客户端幂等键。成功响应 `{}` 代表接纳，完成状态必须通过真实 `turn/*`、`item/*` 与历史核对。源事件的压缩轮次关联和不确定接纳须由 adapter 验证，重启后不能自动再执行一次；源历史无法证实时保持未知。

## 实现与回归记录

- 中立 capability、可选 adapter 接口与持久 `ContextAction` 已接入；worker 协议 minor 29，数据库 schema 10，旧普通 operation 保留空 kind。
- 首次发送前先落盘，重复 ID 校验完整请求；已确认的 RPC 与执行完成分别记录。GUI／worker 恢复只核对，没有源幂等键时不自动重发。保存线程 Resume 的只读元数据变化不会拒绝正确的首次压缩请求。
- 原生圆环 hover 与 `/compact` 走同一操作。过滤不重建弹窗，Tab 只补全命令，Enter 执行；普通草稿、附件和后来输入不被旧回执清除。历史编辑和子 Agent 输入保留文本语义。
- 回执携带权威会话 revision，拒绝旧 journal 覆盖；临时状态与真实压缩内容共用 key、间距、动画时钟和旋转相位。较旧的 running item 不能覆盖已核对的终态。
- `TestRealManualCompactionUsesOwnTurnWithoutUserInput` 使用真实隔离 Codex App Server 与本地确定性 provider 验证源轮次／内容／用量／持久历史。`TestRealWorkerCompactionKeepsSessionAndInputHistory` 验证真实源经 worker 的接纳、原配置与线程保持、无伪造用户消息和重复操作不重发；均不调用付费模型或更改用户凭据。
- Store／worker 测试覆盖忙碌子执行、请求、分支与未知状态禁用，持久重放，旧压缩事件不能结算新操作，已确认接纳后运行时丢失及只读核对。原生测试覆盖菜单键盘、无闪烁交接、旧事件、普通输入排队和维护无完成通知。
