# 会话文件链接

2026-11-15。用户在讨论统一的文件获取与展示流程后要求“ok，实现吧”。本轮按该批准范围实现，保持原生界面，不构建、安装或重启运行中的 App/worker。

- HTTP、HTTPS、mailto 保留外部打开；页内锚点保留 Markdown 导航。
- 本地文件路径、file URL、相对执行目录的路径统一交给会话所属 worker。file URL 的 localhost 指所属设备，不指控制 Mac。解析 URL 转义以及源代码行/列后缀。
- Worker 仅从已接纳的会话目录和设备临时目录读取普通文件；不因工作区后来增添目录扩大既有会话权限。使用 OpenRoot 限制符号链接，目录和特殊文件不可读取。
- 独立只读资源 RPC 与认证连接分块下载，不扩大模型附件限制。下载期间核对文件身份、大小、修改时间和变更时间；文件变化则失败并允许重试。
- 客户端缓存按设备、工作区、会话、路径和文件版本隔离，并验证本机缓存 SHA256。临时下载失败/取消后删除。已完成资源纳入“本机显示缓存”的清理。
- 现有解码范围内的图片、UTF-8 文本和代码沿用原生只读预览及另存为。媒体、PDF、RTF、Office/OpenDocument 文档交默认应用；未知格式提供保存及打开缓存目录。默认应用打开由缓存文件的本机扩展名类型决定，远端 MIME 不授予打开权限；文件链接不自动运行可执行文件。
- 展示连接/下载进度、取消、重试和打开失败。切换会话、连接 epoch 或移除右侧会话后，不接纳迟到结果；关闭窗口取消主、次面板仍在进行的下载。

实现边界：资源下载不受 8 MiB 模型附件限制；原生预览仍沿用现有有界解码能力，超出可预览范围保留通用文件操作。没有真实远端设备可用于本轮端到端验收，使用真实 worker 协议与认证对端覆盖设备隔离，并单独检查 SSH/嵌入网络仍经现有 transport 路由。

用户验收补充：文件弹窗收紧为 360 DIP 宽，10 DIP 内容边距，8 DIP 纵向间距；底部操作文字与标题/文件名对齐。所有控件仍保留公共命中区域与字体。

最终补充：以文件名直接作为标题，删除正文中的重复文件名；保持下载状态在标题下。
