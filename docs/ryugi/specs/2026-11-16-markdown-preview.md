# 应用内 Markdown 文件预览

2026-11-16，用户批准 `.ryugi/artifacts/artboard/markdown-preview` 的亮色、暗色和窄窗口设计，要求开始实现。

- 复用现有原生附件／文件预览，`.md`、`.markdown`（忽略大小写）默认展示 MyGo Markdown；其他文本／代码和图片保留现有行为。文件名、关闭和另存到本机固定在顶部。
- 顶部增加共用灰阶“预览 / 源码”分段切换，源码只读。两种模式分别保留阅读位置；切换使用既有横向动效，尊重减少动态效果。不修改文件或会话草稿。
- 浮层最大宽 840 DIP、外围 14 DIP、图标命中 28 DIP。Markdown 浮层最大高 688 DIP，按可用窗口收紧；正文最长 688 DIP、14 / 24 阅读级别。标题、引用、表格、列表、任务列表和代码使用原生组件，表格与代码可横向滚动，标题栏不随正文滚动。
- 文件沿用所属 worker 的下载与有界预览。空 Markdown 显示“文件为空”；下载失败保留既有取消／重试。超出已有预览范围保留通用文件操作。
- Markdown 中的页内锚点在当前文档导航；HTTP/HTTPS/mailto 链接沿用既有外部打开与菜单。相对文件链接和图片按文档在所属设备上的真实路径解析，不按本机缓存目录解析。继续通过原会话和 worker 的已接纳目录边界读取。附件没有原始路径时，不猜测设备目录；图片保留描述，文件链接提示无法解析。
- 本地图片异步经所属 worker 加载；外部图片不自动请求。HTML、脚本、代码不执行。不支持的扩展语法保留原生可读回退，源码始终可核对。
- 关闭／换会话／换连接后丢弃迟到资源，取消正在进行的图片读取；图片缓存随本次预览销毁，控制有界资源使用。

验证：原生 UI 测试覆盖默认路由、切换／位置保持、空文件、相对链接与设备隔离、异步关闭和安全回退；运行项目 Go 测试、race、冻结设计与录制校验。使用隔离原生窗口拍摄亮暗截图、窄窗口与交互视频，在原设计画板 Verify 页展示，不安装或重启用户运行中的应用／worker。
