# 远程附件上传与路径引用

用户已在 `artboard/remote-attachment-upload` 的 `round-1` 提交 `inline`，并明确要求开始实现。采用设计稿 A：输入框上方原位确认；沿用 MyGo 原生会话、表单和行内引用组件。

## 确认与归属

仅类型不支持、需要转为路径引用的本机文件进入此流程；本机目标仍附本机绝对路径，正常图片／文本附件沿用现有流程。首次向每台远程设备上传时展示目标设备、文件名及大小。明确点击“上传并引用”前不传文件内容。“对此设备不再提示”默认关闭，只有确认时才按稳定设备身份持久化；取消不记住该次勾选。

本地先保留不可变私有快照。草稿正文、队列编辑、历史原位编辑保持独立；迟到结果不得跨设备、工作区、会话或草稿回填。切换连接路径不改变设备身份，也不让另一台设备继承确认。

## 上传与引用

分块上传通过所属设备的独立认证连接，支持真实已确认字节进度、逐项及整体取消。上传中或失败项未移除时禁止遗漏附件而发送。成功的文件形成可选择、复制、撤销的原生行内“图标＋文件名”标签；正文不重置、不自动发送。部分失败保留已完成文件及草稿，重试只处理失败文件。移除失败项后可以发送其他内容。

worker 私有资源由工作区和随机资源 ID 绑定，校验实际大小、摘要、不可变元数据、完整提交及来源归属。worker 决定实际文件路径；控制端不得提交任意远程目标路径。adapter 把这一中立文件路径资源翻译为其实际支持的输入，不将二进制假装成文本／图片，不自动执行文件，不扩大文件／写入权限。普通发送、队列、Steer、历史重开和分叉保留相同资源语义。

## 边界与工程默认

继续使用单文件 8 MiB、每条最多 8 个文件、合计 16 MiB。目录、空文件、读取失败及大小超限继续报错。旧 worker 明确要求升级，正常旧版文本／图片流程保留。会话重启不自动补发消息；已确认但未完成的上传在客户端重启后提示重试。取消后的私有临时字节沿用现有资源生命周期，不能误删其他草稿／历史资源。
