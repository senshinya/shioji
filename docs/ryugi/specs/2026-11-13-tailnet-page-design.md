# Tailnet 网络管理页精修

2026-11-13 用户已确认 `artboard/tailnet-setup` 的 `network-refinement` 页，并要求实现。

- 原生 MyGo 页面，沿用灰阶、系统字体及共用表单和动效。不修改节点身份、登录方式或后台服务生命周期。
- 管理页去掉 840 DIP 靠左宽度限制；标题、节点区、设备列表左右均留 32 DIP。加入和授权表单独立保持 560 DIP，在右侧内容区居中，内部字段左对齐。
- 本机节点区使用官方 Tailscale 标记、节点名称和网络账号；连接状态和开关同行。地址、复制按钮与入站开关共用右边缘，入站转发不单独增加分隔线。
- 已加入网络显示只读可见设备列表，禁止添加设备。展示名称、地址、真实在线状态及往返延迟；详情展开显示地址复制、实际路径、延迟和系统。离线或旧测量标记上次，不将未知值作为零。
- 连接中持续旋转，状态文字原位过渡；设备详情按实际高度 260 ms 展开/收起，箭头同步旋转，遵守减少动态效果。使用实际操作刷新网络设备列表，不伪造成功状态。
- 退出网络放在页头菜单内，经确认才提交。复制图标短暂变为对勾，随后恢复。暂停、未加入、授权等待和失败状态保留原有操作边界。
