# 子 Agent 定向输入（B，2026-11-10）
批准依据：用户在 subagent-input 交互稿选 B，并明确要求开始实现。
- 子 Agent 详情默认只显示“发送消息”入口；完成时显示“继续执行”。点击原地以真实高度展开紧凑输入框，收起保留草稿。
- 当前子 Agent 身份与已归属会话为唯一发送目标；主输入框与后台任务互不影响。草稿按 device/session/work 保存于客户端视图，不按标题归属。
- 运行中仅在具备实际定向追加能力时发送，完成后仅在具备继续能力时继续；不支持时明确不可用，不替代为父输入或停止。
- 发送使用上箭头；既有详情左右切换和文字排版不变。展开收起240ms，新内容跟随现有渐显；仅在原本跟随底部时自动跟随。
- worker 持久化稳定操作 ID、目标、文本及接纳状态；重复 ID 不重复发送，未知只查询。接纳成功后清空该草稿；明确拒绝保留，可用新操作重试。发送时锁定该子输入。
- 子消息保存在该 work 的独立记录中，权威重开不污染主会话。问题/授权继续进入现有共用请求栏。
- Codex 转译层使用真实支持的协议与子执行绑定，不把具体 wire 结构放进共享层；必须验证真实 App Server 下追加与继续，不用真实账号或付费请求。
- 生产实现为 Go/MyGo。参考交互稿位于 .ryugi/artifacts/artboard/subagent-input，仅作原型，不包含运行依赖。
