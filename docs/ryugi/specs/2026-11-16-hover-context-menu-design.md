# Hover 与右键菜单统一：现状与设计草案

状态：2026-11-16 用户已确认设计，进入实施。用户补充已纳入：导航浮层左边缘垂直中点对准 hover 刻度；会话超链提供右键另存为及用默认应用打开，重点覆盖文件链接。

视觉稿：本地 Ryugi `artboard/hover-context-menu`，包括源码现状、浅色、深色和导航锚点四张静态稿。页面表现的是提案，不是应用运行截图。保留 `design/` 冻结基线。

## 方向

- 产品：个人开发者在原生 macOS 客户端阅读、输入并管理多个设备上的 Agent。
- 气质：安静、紧凑、位置稳定。
- 材料：既有系统字体、中性灰表面和项目业务图标。
- 重点：指针与键盘看到同样的反馈；同一对象的右键和省略号打开同一份操作。
- 共同细节：固定文字列、稳定命中区、浮层依附真实目标；不增加装饰、蓝色选中或 logo。

本次是公共交互层整理，涉及应用和 MyGo 菜单层，属于跨组件改动。以下新增规则均为建议，不能视为已经验收的行为。

## 2. 统一原则

统一公共渲染和交互基础，保留三种不同语义：

1. **控件反馈**：立即给出可操作感，统一到现有 controlFeedback／textHoverColor／fieldFeedback；不为每个页面复制 Hovered 分支。
2. **悬浮信息**：普通短提示与可进入的信息浮层共用样式、边界避让及目标生命周期；延迟、是否可移入按语义明确区分。
3. **操作菜单**：业务右键与省略号共用 MyGo 原生绘制菜单引擎和同一动作构建函数；右键以指针落点定位，按钮以按钮下沿定位。

“原生绘制”指 Go + MyGo UI，不引入 WebView。浏览器稿仅表达视觉和定位。

## 3. Hover 视觉与时序

| 类型 | 建议规则 |
| --- | --- |
| 图标按钮／普通操作行 | 保留当前 120 ms 中性 feedback，按下加深；图标按钮 28 × 28、槽位 16；状态变化不移动图标和文字 |
| 工具行／footer 文字动作 | 继续只提亮文字；鼠标、键盘焦点和按下都使用公共计算 |
| 输入框 | 使用现有 fieldFeedback；composer 保留当前固定边框约束 |
| 菜单项 | hover 与键盘活动项使用同一中性 selection surface，避免额外叠两层底色；当前勾选与活动项相互独立 |
| 行内隐藏操作 | Hovered、FocusWithin 或该行菜单已打开时显示；预留槽位／沿用队列宽度动画，关闭菜单后重新按指针和焦点决定 |
| 禁用动作 | 不出现可点击的 hover 填色、不执行；原因由非操作宿主提示，辅助描述同样可读 |
| 普通 tooltip | 延用 MyGo 600 ms 首次／400 ms warm／键盘立即；不重复写计时器。建议改为 raised 表面、1 DIP 边框、6 DIP 圆角、6／10 DIP inset、12／18 DIP 字体、最大宽 320，距目标 6；上方优先，边界不足翻转 |
| 短提示生命周期 | 指针离开、按下、Esc、目标消失即关闭；不拦截选区和点击；快捷键说明按现有项目约束保留或省略，不全局额外补上 |
| 信息 hover card | 沿用上下文的立即开／离开 180 ms 收；触发器到面板的通路可穿越；面板 hover 或 FocusWithin 保持打开。hover 本身不移动键盘焦点；Esc／外点后原地停留不反复打开 |
| 减少动态效果 | 保留现有至多 60 ms 颜色变化；浮层关闭缩放。对话刻度与定位直接切换，不出现位移／缩放动画 |

同一窗口内菜单打开时，关闭普通 tooltip 和只读导航预览；有交互的既有选择器由明确的 overlay 顺序接管。不能只用一个任意全局布尔值取消其他窗口或另一会话的输入行为。

## 4. 对话导航：本轮用户明确的锚点

浮层放在 hover 刻度右侧，**左边缘的垂直中点与当前 hover 刻度中心对齐**，不是对齐整个导航轨道，也不是将浮层底部放在刻度上。

布局以实际测量高度为准：

```text
anchorY = tick.Y + tick.H / 2
preferredY = anchorY - measuredPreviewHeight / 2
Y = clamp(preferredY, visibleReadingTop + 8,
          visibleReadingBottom - 8 - measuredPreviewHeight)
X = tickVisibleRight + 14
```

这里的 visibleReadingTop／Bottom 是工具栏以下、底部输入／待处理区以上的真实阅读边界。靠边时整体避让，允许偏离中心，但不改成底部锚定；不要用固定 160 DIP 估算高度。水平优先保留右侧，空间不足则限制宽度或沿用窄面板隐藏导航规则，不覆盖 composer。

宽 320、padding 8、radius 12，用户消息 1 行／回复最多 3 行，按真实内容测量高度。初次等待 200 ms；同一轨道连续切换刻度即刻更新，离开后重置。hover 不跳转、不抢焦点；点击／Enter 才导航，键盘上下／Home／End 与 Esc 按既有冻结稿补齐。

## 5. 右键菜单设计

### 外观

普通业务菜单使用冻结 `design/menus.css`：行高 26 DIP、字体 13／20 DIP、外围 3 DIP、外圆角 7 DIP、行圆角 4 DIP、水平 inset 7 DIP。有图标时用 14 DIP 共同槽；不为每个已有文字动作补图标。长文字按场景截断或换行，菜单仅纵向滚动，分隔线留在滚动区内。截图样例宽 216 DIP，实际按最长标签／已有场景宽度决定。

浅色面板 #fff、hover #eee、正文 #1c1c1c；深色面板 #2d2d2d、活动行使用现有 menuSelectionSurface（raised 与 Text 混合 12%）、正文 #e9e9e9。焦点不使用 Accent 黑／白反色，活动项与鼠标 hover 视觉一致。分隔线／阴影沿用项目中性灰。不新增危险色来重新解释归档等动作。

运行配置保留已确认的特殊尺寸：240 DIP、28 DIP 行、4 DIP inset、9 DIP 外圆角，以及选择子项后返回主菜单／开关不关闭的行为。它可以共用样式与锚点基础，不强行改为普通 action menu 的单选即关闭生命周期。

### 交互

- 会话、工作区右键和省略号共用已有构建函数；右键未选中会话时不先导航、不换草稿，动作绑定被右击对象的稳定身份。
- 菜单打开期间保持来源行的操作可见；不会因指针进入菜单而隐藏按钮、扩大标题或移动锚点。
- 右键／Control-click、菜单键／Shift+F10 都可进入。键盘打开首个可用项；上下／Home／End 跳过禁用项；Enter／Space 执行，Esc 逐层返回，根菜单关闭后归还原有焦点。对象菜单不得夺走另一个输入框的选区或 IME 状态。
- 普通 action 选中后关闭；不改变 worker 的接纳、权限或确认边界。禁用项保留可访问语义。
- 子菜单复用同一引擎；建议鼠标停留 200 ms 打开，点击／右键盘箭头立即打开，经过菜单间隙不闪关。这个 200 ms 是本轮建议值，冻结稿只要求“延迟”。
- 目标滚动、虚拟行卸载、切换会话／设备、窗口失焦时关闭，不把菜单转移到同位置的另一行。菜单内长列表可滚动到底，避让窗口边界。

### 文本编辑边界与推荐决策

推荐统一应用内容区的业务菜单与文本右键外观：输入框和可选文字也使用同一 MyGo 绘制菜单，但继续从现有 editCommands／EditItems 派生命令、可用性和剪贴板操作，不在应用层重写输入行为。链接优先给出链接操作，再按实际选区合并编辑项；命令标题／消息空白可给对象动作，命中正文选区保留“复制所选”。输入控件不继承外层会话／消息的破坏性动作。

这是需要 MyGo 小范围补足的建议：自动文本编辑菜单当前仍直接走系统弹出；只改业务调用为 PopoverMenu 无法完成全文本右键统一。可先验证一个带原生选区的 MyGo 纵向切片，确认焦点／选区／密码限制后再迁移全部调用。系统菜单栏、macOS 文件选择器和系统窗口保留系统拥有的交互。

### 会话超链补充（用户明确要求）

会话正文（含 Markdown、工具内容和普通用户消息）中的文件、HTTP／HTTPS 链接提供“用默认应用打开”“另存为…”和复制地址。文件路径继续由所属会话的 owning worker 解析与下载，默认应用只接收已校验的本机副本；显式打开可覆盖文本／代码文件，不自动运行可执行文件或脚本包。普通左键的原有预览行为不变。HTTP／HTTPS 另存为保存实际响应字节，保留路径给出的文件名；出错保留重试和取消，不用错误页面覆盖目标。远程 loopback HTTP 从所属设备连接读取，不能误读控制 Mac 的 localhost。保存由系统保存面板选择本机位置，取消不写入；迟到结果不得在另一设备／会话自动打开。文本选区仍保留复制所选，不以复制链接替换它。

## 6. 实现边界与迁移建议

不创建通用动作注册中心或第二套菜单引擎。

1. **MyGo 最小补足**：在现有 PopoverMenu 引擎增加可选的样式配置（默认行为不变），覆盖密度、surface、活动项和子菜单延迟；让自动文本编辑菜单可选择同一绘制路径。具体 API 名称在实现时依据框架既有扩展方式确定。
2. **应用公共层**：现有 `motion.go` 继续负责反馈；新增小范围 tooltip 外观／禁用原因宿主与 hover-card 公共函数；现有 `menus.go` 负责本项目菜单样式。复用稳定 key 与现有 overlay 生命周期，不建立万能弹层状态机。
3. **第一组迁移**：侧栏会话右键／省略号、工作区右键和一处文本选区；先验证同一动作、目标身份、焦点归还和菜单中持续显隐。
4. **其余迁移**：设备详情／路径、历史消息、命令、用户及 Markdown 链接、端口转发地址；保留现有的每一项业务就绪／权限判断。
5. **Hover 收口**：替换重复外观与状态判断，保留工具行纯文字、队列动画、输入边框等既有差异。导航采用独立中心锚点与实际高度计算。

普通 choiceMenu 可复用菜单引擎的选择语义与样式；分支搜索、Permission 的说明列和运行配置保留各自实际内容／焦点需求，不为“统一”丢掉搜索、稳定列或连续配置能力。

## 7. 后续实现验收

- 亮暗模式、中英文／混排、长标签、多行、禁用、减少动态效果；图标字面对齐误差不超过 1 DIP。
- 按钮 hover／键盘焦点／按下／移出，工具行只提亮文字；选中表面不被 hover 覆盖，禁用原因可见且动作不执行。
- 右键和省略号动作一致；对未选中会话右键不切换；连接变化、滚动卸载、会话切换后不会操作错对象。
- 普通提示单例、延迟／warm、Esc、按下关闭、菜单互斥；信息卡可穿越间隙、不抢 composer 焦点，不因后台数据更新重开。
- 导航中间刻度：预览左边中点误差 ≤ 1 DIP；分别测单行／三行回复、首末刻度、可变 composer／问题区高度、顶部／底部碰撞。连续 hover 不重等 200 ms，阅读位置与普通草稿保持。
- 文本／Markdown／链接精确命中、跨块选区、复制所选／整条区分；编辑菜单、密码字段、中文 IME、原生撤销、VoiceOver 和焦点恢复。
- 真正 darwin/arm64 原生截图与交互验证；浏览器稿和源码计数不替代原生证据。合并冲突处理后再运行相关 Go 测试及必要构建。

## 8. 实施记录

原生公共菜单已接入 MyGo 的可选 `Theme.MenuStyle`、`Context.UsePopoverMenus`，业务 ContextMenu／Menu 与自动文本编辑菜单复用同一绘制引擎。未启用的应用保留原路径。富文本组件通过 `CanEditCommand` 提供自身命令可用性，内联链接从所属段落带入 EditItems；不重写选区或输入法。框架 Tester 的菜单辅助也可读取自绘菜单，但真实交互测试另用实际指针／按键验证。

普通提示使用共享 TooltipStyle，禁用控件只提供只读说明，不获得可执行状态。上下文详情使用 `hoverCard`，保留立即展开、180 ms 离开宽限与不抢焦点。导航在 200 ms 后开始呈现，先测量实际高度，再以左侧中点锚定；长短内容、连续浏览、Esc、Home／End 和普通草稿均有回归。

文件及 HTTP／HTTPS 右键可另存为，文档／文本／代码文件可显式用默认应用打开；可执行包、命令脚本等仍不由链接启动。左键保留原预览策略，普通用户消息中的 file:// 也按所属设备处理。网络另存为通过 owning worker 的已认证 TCP 流下载，无本机临时监听端口；本机系统保存面板选择目标，原子复制已完整下载的副本。错误状态码、取消、下载部分文件清理、缓存文件地址及源会话身份均有覆盖。

运行窗口证据使用生产 View 与明确的本地夹具数据，未连接用户设备、启动 Agent 或修改用户配置。导航旧版对照使用原导航源码的 Go build overlay，在同一夹具中运行真实 MyGo 窗口；新旧窗口截图与菜单交互录屏放在原画板的 Verify 页。网络字节／身份路由由实际协议流与 HTTP 服务的集成测试验证；截图不冒充真实设备或物理 IME／VoiceOver 验收。
