## 原生实施边界

使用 MyGo 原生 Path/Painter 与文字/控件，不嵌入 HTML 或 WebView。图形与命中区域共享几何，文字使用原生字体与基线度量、共同的行高，数字使用 tabular figures；图形缩放与字号分开。亮暗、600/850/1240 DIP、中文/英文混排、长地区名、一个/两个/更多同类路径、本机和离线均验证。路径 ID 只作稳定身份，不解析其拼写。
