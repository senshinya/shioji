# 会话搜索与精确定位

用户确认开始会话内搜索、全局结果定位和长历史衔接。最新反馈：会话内查找平滑滚动，高亮不放大且持续到关闭搜索；全局结果只定位消息，不打开会话内搜索框。沿用原生 Go/MyGo、中性浮层和现有 owning-worker 搜索／分页补读，不改冻结稿，不引入依赖。

## 行为

- ⌘F 在当前焦点会话右上方打开紧凑搜索条，13px 输入、11px 等宽计数、24px 上下条与关闭按钮。Enter／Shift+Enter 与 ⌘G／⇧⌘G 前后切换，循环导航；Esc 关闭并恢复输入焦点，普通草稿和编辑稿不变。双会话各有独立查询及当前位置。
- 当前会话对已补读的用户消息、助手正文和工具内容做字面查找，跨 Markdown 和代码逐条定位。保存每项命中数，按需求当前命中的偏移，不为每一个字符创建命中对象，不随每帧重新扫描未变化正文。
- 全局搜索沿用已连接设备的聚合，结果携带源消息 ID 和 UTF-8 字节范围，摘要围绕关键词截取并保持完整字符。标题命中可以只打开会话；正文命中必须定位到具体消息和关键词。
- 结果尚未补读时保留定位意图，等待现有 worker 分页历史加载，按稳定消息 ID 定位；完整历史到达或工具默认折叠不得释放定位锚点。目标被另一客户端替换时不定位到无关消息。
- 命中隐藏工具时只展开目标所在分组。定位用现有滚动锚点动画，长消息中按真实文字几何对齐关键词。高亮不修改 Markdown、不接管文字选择、不改变行距或正文布局。
- 会话内当前命中使用固定大小的黄色底色，持续到关闭搜索；不放大或定时消失。全局结果使用短暂黄色定位提示，保留先停留再渐隐的节奏，不打开查找框或抢走普通输入焦点。减少动态效果取消滚动插值。
- 查找从当前实际滚动位置连续移动到目标，不沿用发送消息将起点限制到一屏内的处理。动画过程中只构建当前视口附近的行，重新定位时从当前动画位置衔接。

## 原生支持与验证

向 MyGo 文本组件补充只读范围几何，Markdown 使用现有源偏移映射将所选范围转换到段落和代码布局，保持格式与选择独立。测试先复现缺失的 ⌘F、定位摘要和黄色提示，再覆盖重复中英文命中、Markdown／代码范围、淡出、双会话、迟到历史、焦点／草稿与减少动态效果。最后使用隔离 worker 和原生实例生成亮暗／窄窗截图与实际动画证据，保留局域网验收，未授权提交推送。
