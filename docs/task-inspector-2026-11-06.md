## 行为

右侧仍只有一个可调宽面板，默认上方文件更改、下方结构化任务同时可见；会话工具栏也提供任务入口。参考 [Obsidian 的侧栏分组](https://help.obsidian.md/sidebar)和[组间尺寸调整](https://help.obsidian.md/tabs)，上下各自滚动，拖拽水平分隔线调整下部高度并持久化，不引入通用停靠框架。没有结构化任务时，上半区使用全部高度。

拖拽任一视图图标到另一组图标旁可合并为图标标签组，默认选中被拖入的视图。合并状态下拖任一图标到内容区下方，会显示与实际落位高度一致的中性半透明分屏预览，松手后该视图移到下部。图标由原生拖拽跟随鼠标，落位后上下区按同一实际高度变化过渡；切换内容短渐变。Esc 或栏外松手取消，预览不会提前改变布局。保留文件选择、滚动状态、侧栏宽度及编辑草稿。没有任务的会话临时只显示 Diff，不改保存的分组意图。

图标悬停和按住但尚未跨过拖拽阈值时使用普通箭头；实际拖拽期间使用闭合抓手，移出原图标后仍保持抓手，松开或取消后恢复普通光标。文件更改、结构化任务、子 Agent 和后台任务的图标沿用同一规则，分隔线保留其原有尺寸调整光标。

任务步骤只读，展示实际 pending / running / completed 状态，不显示合计进度比例，不从回复正文推断，不因轮次结束自动勾完。默认上下各占一半；每次拖到下方新建分屏，虚影和实际落位均重新按当前侧栏高度均分，之后可拖拽调整并保存。下部最小 120 px，为上方保留至少 240 px。任务到达/清空通过实际布局高度展开/收回，上方跟随同一高度变化；直接拖拽分隔线立即响应。Diff 使用简洁加减图标，任务使用三行列表；图标在 28 px 拖拽按钮内居中，以 16 px 图形槽保持同组可见高度一致。侧栏左侧分隔线位于内容层上方，任务背景不能覆盖它。

文件仍沿用右侧滑入/滑出，返回、文件名和正文同步移动，动画限于 Diff 所在分区；图标标签、其他分区、刷新和关闭不随文件横移。

正在执行的任务左侧使用与消息底部相同的 6 px 绿色呼吸点，未开始使用同尺寸灰色实心点，已完成保留灰勾。进行中的任务文字和消息底部“进行中”使用中性明暗光带 Shimmer，仅改变文字像素，不移动布局或重建对话正文。减少动态效果时停止 Shimmer 和呼吸，取消横向位移并缩短透明度过渡。

## 数据与持久化

- Codex `turn/plan/updated` 归一化为独立 `plan` 事件，保留来源 turn ID，`inProgress` 转为领域状态 `running`。更新整体替换该会话最新计划，空数组清空步骤，其他会话不变。
- Worker SQLite schema 3 增加每会话一份的计划投影，升级保留原有设备、工作区和会话；旧 worker 拒绝写入更新后的数据库。计划不进入普通消息或历史分页，客户端通过 session detail 和有序事件恢复它。
- 协议 minor 3 增加计划字段。分组/分屏状态、视图顺序、合并后的选中项、下部高度与侧栏宽度属于客户端布局状态，独立于会话执行数据持久化。
- 任务文本按单字段及整体编码大小限制，避免超过 IPC 与事件分页预算而阻塞设备事件流；发生截断时明确标注，不把可见子集当成完整进度。

## 会话名称

接收 `thread/name/updated`，以及 thread start/resume 返回的已有名称。名称通过独立事件保存，更新会话列表、工具栏和搜索；不改变执行上下文、状态或会话 ID。后续包含旧名称的生命周期快照不能覆盖名称更新，恢复响应与后续通知按现有事件锁串行处理。没有名称时继续使用首条消息摘要。

这仅同步 Codex 实际提供的名称，不增加独立模型调用来生成标题。Codex 桌面端自动标题功能不能视作 app-server 保证：固定协议提供 name/set 与名称通知，没有单独的自动标题生成请求。

## 验证范围

通知归一化、计划替换/清空、SQLite 升级和重启、跨历史分页恢复、会话隔离、合并/下方停靠、取消拖拽、布局重启恢复、分隔线键盘调整、长内容滚动及单栏文件返回均有回归检查。真实 Codex app-server 的 name/set 通知与重启后 resume 名称恢复已通过隔离本地测试，没有调用付费模型。

当前本机 0.166.0 / gpt-6.1-sol 暴露的工具集中没有旧 `update_plan`，强行调用返回 unsupported call。因此真实计划工具集成测试会在该能力缺失时明确跳过，不能宣称此模型已能自动上报任务步骤。计划事件接入按固定 schema 验证；原生任务截图来自明确标记的协议回放夹具，不能作为真实模型步骤生成的证据。未修改用户 Codex 配置或强制切换功能标志。
