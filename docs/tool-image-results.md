# 工具图片结果

工具查看／生成的图片、MCP 和动态工具返回的内嵌图片，现在通过中立的资源导入回调保存到 owning worker 的附件仓库。回调只接收会话、消息、图片槽位、文件路径或已解码字节；Codex 的 `imageView`、`imageGeneration.result`、`savedPath`、MCP base64／data URL 等表达均在 adapter 内翻译。共享层不解析 harness 的文件 ID，不自动抓取远程 URL。

本地文件只从会话已接纳的主目录或附加目录读取，校验目录身份，以 `os.OpenRoot` 限制软链逃逸，并拒绝非普通文件。图片沿用 PNG/JPEG/GIF、每张 8 MiB、4000 万像素的现有限制；一项工具结果最多导入 8 张。字节位于工作区资源仓库，消息、快照和 journal 只携带不可变的 `Attachment` 引用。

同一工作区、文件名和内容产生稳定的 UUIDv8 资源身份；首次接纳后，恢复和重复事件按消息及图片槽位复用已保存引用，不重新读取后来被覆盖的源路径。下载沿用独立认证连接与摘要校验，不排在停止、回答或事件订阅之前。客户端在有界图片缓存中解码缩略图，失败可重试；查看器继续使用原有不透明图片层的裁切与几何过渡。

缩略图在工具详情内展示，保留原有工具折叠行为；文件名在下方，复用灰阶文字。加载完成用 180ms 实际高度动画调整图片区域，图片进入使用既有轻量动效。点击从缩略图放大、关闭回到原位，复用原生查看器；不增加第二个右栏或 WebView。减少动态效果沿用公共适配。

图片背后的查看器面板也以同一 280ms 进度，从缩略图的边界与中心展开到最终窗口，关闭时同步缩回。面板与图片保持不透明，不在动画末尾切换面板可见性；进入过程中暂不接收面板内操作，Escape 和遮罩仍可关闭。

源协议仅给出文件 ID、没有 `savedPath` 或内嵌内容时，保留该资源身份，不猜测运行时私有路径。音频播放、交互式 MCP App 仍未接入；文本／代码文件结果已在后续[工具文件结果](tool-file-results.md)增量接通。

验证包括：协议的本地路径、内嵌生成结果、MCP 图片／资源、动态工具 data URL、无效编码与图片槽位；worker 的目录归属、软链、资源幂等、原文件改变后的历史复用；另一客户端从独立认证连接下载同一字节；原生图片加载高度、焦点／草稿及缩略图来源放大。真实 Codex app-server 配合本地确定性模型端点产生 `view_image` 结果，用正式原生应用拍摄亮暗截图及开合视频；原图片移走后仍可查看。没有把本地夹具回复表述为在线模型回复。用户已验收通过图片预览及面板同步开合动画。
