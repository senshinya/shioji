# 工具文件结果

在图片快照的资源链路上扩展 UTF-8 文本／代码文件。中立的 `StartOptions.ImportResource` 与 `harness.OutputResource` 携带 `image`／`file` 类型、会话、消息和各类型独立的槽位；adapter 负责翻译编码，worker 负责来源约束和不可变存储。图片原有的槽位顺序保持不变；以前只展示为资源链接的图片链接仍保留原样，避免重开历史时误用后一张图片的快照。

Codex adapter 接通 MCP 内嵌文本资源（允许省略 MIME）、明确文本 MIME 的 base64 资源，以及指向执行设备本地文件的文本资源链接。只在工具完成时导入，不从普通正文、代码块或命令输出猜测路径，不自动请求 HTTP／远程资源 URL，也不把不支持的二进制当作文本。内嵌资源名称来自 URI 的最后一段；本地路径资源使用真实文件名。文件遵循现有非空 UTF-8、无 NUL、128 KiB 限制；同一结果最多导入八份资源，仍保留总体展示边界。

worker 复用已接纳主目录／附加目录的身份校验、`os.OpenRoot`、普通文件及大小检查，消息和 journal 只保存附件引用。恢复及重复事件先按消息、资源类型和槽位复用快照；另一客户端经独立认证连接下载相同内容。原文件后来被改写或移走，不影响已经保存的版本。

原生工具详情以紧凑的文件图标、名称和大小呈现。预览复用现有附件查看器，从所点击入口展开并原位收回；加载后的内容高度与面板高度同步过渡。文本／代码使用 MyGo 的只读编辑器，按文件名做语法高亮，可选择和复制；短文件按内容收紧，长文件在有界区域滚动。保存错误也参与同一个实际高度动画；图片几何终点取实际图片槽位，避免错误文字被图片覆盖。减少动态效果沿用公共适配。

图片及文件的预览顶部均提供“另存到本机”，使用 macOS 系统保存窗口。取消仅关闭系统保存窗口；确认后下载并校验快照，在所选目的地同目录完成临时写入和同步后再原子替换，读取或校验失败不会截断已有目标。无扩展名的图片按已验证 MIME 补默认 PNG／JPEG／GIF 扩展名。普通草稿、原设备文件和 worker 快照不受另存影响，不自动执行文件或打开外部应用。

验证覆盖内嵌文本／blob、本地链接、缺省 MIME、远程链接不抓取、进行中不导入、旧图片索引兼容、跨客户端下载、只读原生预览、图片错误行遮挡、原子导出及损坏副本拒绝。真实 Codex app-server 通过本地 MCP 服务返回 Go、中文 Markdown、Python 文件和图片；Responses 端点是确定性本地夹具，回复与用量不是在线模型结果。源 Python 文件在 GUI 下载前已移走，预览仍成功；系统保存、取消及导出后摘要对比已实机验证。视觉效果待用户验收。

最终全套 `go test ./...`、附件／adapter／worker／UI 重点 race、`go vet ./...`、53 条固定协议帧及 6 份仓库冻结设计检查通过，开发签名构建通过。亮暗截图与真实原生开合录像位于局域网 Ryugi 验收页；实际 HTTP 地址完成渲染，媒体完整加载及播放，错误收集为空。UUID v4 补丁在主模块前加载，未修改 Ryugi 安装或降低浏览器安全限制。新增内容与缓存、媒体均未自动提交。

## 缩放端点修正

用户指出文件预览像从尖点展开。原生回归确认：360×36 的文件卡片被统一等比 fit 缩放成约 163×36，展开起点与收回终点均未覆盖完整入口。文件和图片现在共用同一组按宽、高分别匹配来源边界的计算，两个端点都精确还原完整卡片／缩略图的位置与尺寸，仍保留实际内容高度动画。运行菜单及共用浮层保持轻微等比缩放，不使用将长条入口压窄的 fit 计算；菜单新增形状比例回归。全套 UI/Go 检查及原生文件、图片、菜单往返已验证，同亮色、同会话的前后录像已更新到验收页，等待用户复核。

后续按反馈补齐样式本身的交接：工具文件、草稿附件、历史附件及行内引用保留各自实际缩略内容，沿同一进度与展开内容交替显示；文件窗口使用真实宽高、背景、边框和圆角过渡，避免把整个阅读器压缩后在最后一帧换皮。图像像素继续使用独立不透明层，窗口外观和遮罩随进度渐变；关闭行内图片标签也保留挂载直到归零。像素回归验证文件大小文字在进入时逐步变淡、退出过程中恢复，图像遮罩存在中间亮度；行内关闭、图片替换与减少动态效果回归通过。用户已在原生界面验收本轮样式过渡。文件块与图片块的独立追加／入场动画已在后续[消息区动态内容](message-area-motion.md)中补齐。
