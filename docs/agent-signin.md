# Agent 登录与重新认证

设备页与首次初始化复用现有账号展开区。账号未登录或登录过期时可展开并登录；本机和 SSH 设备均可选择浏览器或验证码授权；独立下拉框靠左并与同列输入框对齐，选择“浏览器授权／验证码授权”；右侧“登录／重新登录”按钮发起授权，不在可执行文件下方重复增加登录入口；选择方式本身不发起登录。本机默认浏览器，SSH 默认验证码；仅一种方式可用时显示方式名称与独立登录按钮。入口由所属设备 Agent 的实际协议能力决定；旧 worker 或缺少相应能力时保留已有登录命令入口。不会安装 Agent、退出现有账号或接收账号密码／API Key。

`AuthenticationProvider` 是独立中立能力，只接收授权方式并返回临时公开挑战、可取消的登录句柄和经过核验的账号／模型元数据。具体登录参数、来源登录 ID、授权通知及凭据存储属于 adapter。浏览器若需要执行设备的回环回调，adapter 将其翻译为中立的 LoopbackEndpoint，不把 OAuth 参数或固定端口放入共享层。Codex 先检查安装协议中对应登录变体、取消及账号读取能力，再启动独立的认证 app-server；无需已有登录或模型目录即可开始。完成通知必须匹配该次登录 ID，并重新读取账号和模型，不能仅凭浏览器跳转宣称成功。

worker 持有 starting → waiting → completed / failed / canceled / expired 的授权生命周期，每个 harness 最多保留一项，授权最长十分钟。相同 ID 和配置重复 start 只查询现有结果；状态查询找不到 ID 时返回过期，不重新发起。取消仅作用于该登录，不退出账号，不停止会话或后台工具。活跃授权会阻止 worker 更新及受管后台服务停止。worker 正常退出会取消并关闭认证进程。

协议 minor 19 增加 `runtime.signin.start/status/cancel`；minor 20 增加远程浏览器所需回调契约，旧远程服务保留验证码登录，更新前不开放浏览器选项。本机与已保存 SSH 设备通过原有认证连接调用；尚未添加的 SSH 设备通过已有校验结果中的 DeviceID、worker 和 state 路径独立连接，严格校验设备身份，不借用控制端运行环境。登录过程不依赖某个 GUI/SSH 请求持续存在。

授权 URL 与验证码只存在于临时内存和认证连接回执，不写数据库、journal、日志或客户端草稿。客户端只持久化所属连接／harness 和不透明操作 ID，发起前完成落盘；重连或重启只查询该 ID，未知结果不重放。应用重开不会自动打开浏览器。外部链接必须是无 userinfo 的 HTTPS URL；不会传输或复制执行设备上的认证文件。

账号、登录入口与验证码区域沿用同步的实际高度展开／收起，状态及账号元数据使用既有文字过渡；方式选择器、授权操作的进退场及按钮文案变化使用公共过渡，尊重减少动态效果。授权页打开失败保留再次打开入口；取消、过期、失败清除挑战，允许重试；登录未完成、过期、连接与授权页打开失败等提示共用按钮行左侧状态槽，单行截断并悬停显示全文，不另起提示行。完成后自动更新账号和模型，保留编辑草稿与 Agent 启用选择；授权期间切换配置后不将旧账号元数据套到新配置。未保存的配置可发起登录，但登录不替用户保存该配置；取消配置编辑保持原有保存语义。

验证：适配层实际 JSON-RPC 进程夹具覆盖完成通知早于回执、无关通知、取消关联、非法 URL 和账号／目录核验；worker 覆盖幂等、未知查询、临时数据、取消隔离和服务维护；原生 UI 覆盖设备／配置作用域、首次 SSH、丢失回执、重启查询、失败重试、草稿与高度动画。实际已安装 app-server 在隔离目录分别完成浏览器和验证码授权的发起／取消；未提交账号授权。最终账号授权与真实 SSH 端到端登录仍需用户选择账号完成，不将协议夹具的成功状态冒充真实账号登录。

远程浏览器在控制 Mac 打开。控制器先绑定所需本机回环端口；`localhost` 同时绑定 IPv4 和 IPv6，任一被占用都释放本次绑定并行内报错，不抢占、不改授权 URL。回调字节经已有严格主机验证的 SSH `-W` 通道原样送到执行设备的回环端点，不运行远端 shell 命令，不记录或解析授权码。应用在转发可用后才打开浏览器，失败保留取消入口，由用户选择是否改用验证码。转发由控制器持有，完成、失败、取消、过期或退出时清理；重连只重建回调，不重放账号登录。网页授权状态不改变 worker 作为凭据拥有方的边界。
